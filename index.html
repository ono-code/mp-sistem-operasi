Fungsi Utama & Peran Sistem Operasi

Sistem Operasi (Operating System / OS) adalah perangkat lunak sistem terpenting yang bertindak sebagai jembatan penengah antara perangkat keras (hardware) dan pengguna (user/aplikasi), serta mengelola seluruh sumber daya komputer agar bekerja secara efisien, aman, dan teratur.

Daftar Sub-Topik

Topik 01

Pengertian, Peran, dan Hirarki Sistem Operasi

Tanpa sistem operasi, komputer hanyalah sekumpulan komponen elektronik mati yang tidak dapat digunakan. Sistem operasi berfungsi sebagai **Resource Allocator** (Pengalokasi Sumber Daya) dan **Control Program** (Program Pengontrol).

Hirarki Layer Komputer

USER (Pengguna Komputer)
APLIKASI (Web Browser, Game, MS Word, Video Player)
SISTEM OPERASI (Kernel, Drivers, System Services)
HARDWARE (CPU, RAM, Harddisk/SSD, GPU, Perangkat I/O)

Resource Manager

Mengatur dan mengalokasikan CPU time, memori RAM, ruang disk, serta saluran komunikasi I/O secara adil dan efisien antar aplikasi yang berjalan secara bersamaan.

Control Program

Mengawasi eksekusi program pengguna untuk mencegah terjadinya error, konflik antar aplikasi, dan akses ilegal terhadap perangkat keras.

Topik 02

Manajemen Proses & CPU Scheduling

**Proses** adalah program yang sedang dieksekusi oleh CPU. Karena CPU bekerja sangat cepat, sistem operasi melakukan teknik **Multitasking** dan **Scheduling** (penjadwalan) agar komputer terkesan dapat menjalankan banyak aplikasi dalam waktu bersamaan.

5 Status Siklus Hidup Proses (State):

  • 1. New: Proses baru diciptakan.
  • 2. Ready: Siap dieksekusi, menunggu giliran CPU.
  • 3. Running: Instruksi sedang dijalankan oleh CPU.
  • 4. Waiting/Blocked: Menunggu event (contoh: input keyboard/baca file).
  • 5. Terminated: Proses selesai atau dihentikan.

Penanganan Deadlock:

Deadlock terjadi ketika dua atau lebih proses saling mengunci dan menunggu sumber daya yang dipegang oleh proses lain secara permanen. OS bertugas mencegah, mendeteksi, atau menghentikan situasi deadlock tersebut.

Topik 03

Manajemen Memori Utama (RAM & Virtual Memory)

Memori Utama (RAM) adalah tempat penyimpanan sementara berkecepatan tinggi yang menyimpan data dan instruksi yang sedang diproses CPU. Sistem operasi mengatur alokasi dan dealokasi ruang memori untuk setiap program.

Alokasi & Protection

OS mencatat bagian memori mana yang sedang digunakan dan siapa yang menggunakannya. OS juga menjaga isolasi agar satu aplikasi tidak merusak area memori milik aplikasi lain.

Virtual Memory & Paging

Ketika RAM fisik hampir habis, OS memindahkan sebagian data inactive ke ruang khusus penyimpanan secondary (harddisk/SSD) yang disebut **Page File / Swap Space**. Ini memungkinkan komputer menjalankan program besar melebihi kapasitas fisik RAM.

Topik 04

Manajemen Penyimpanan & File System

Penyimpanan sekunder (Secondary Storage) bersifat non-volatile (data tidak hilang saat listrik mati). OS menyediakan bentuk abstraksi logis dari informasi penyimpanan dalam bentuk **File** dan **Folder/Direktori**.

Fungsi File System (Sistem Berkas):

  • Memetakan berkas ke media fisik (sector/cluster disk).
  • Mengelola struktur hierarki direktori (pohon direktori).
  • Menyimpan atribut berkas (nama, ukuran, tanggal buat, hak akses permission).
Contoh File System: NTFS & FAT32 (Windows), ext4 (Linux), APFS (macOS).
Topik 05

Manajemen Perangkat Input/Output (I/O) & Driver

Komputer terhubung dengan berbagai perangkat periferal (keyboard, mouse, printer, scanner, GPU, dll). OS menyembunyikan rumitnya perbedaan spesifikasi hardware melalui **Device Drivers**.

1. Device Driver

Software khusus penerjemah antara OS dan perintah fisik perangkat keras spesifik.

2. Buffering

Menyimpan sementara data I/O untuk menyelaraskan perbedaan kecepatan transfer perangkat.

3. Spooling

Mengantrekan tugas I/O (seperti dokumen yang akan dicetak di printer) di memori/disk.

Topik 06

Antarmuka Pengguna & Proteksi Keamanan

OS memberikan antarmuka bagi pengguna untuk berinteraksi dengan komputer, serta menjaga keamanan data dari akses yang tidak sah.

Jenis User Interface (UI)

  • CLI (Command Line Interface): Teks berbasis perintah ketikan (CMD, Terminal Bash). Ringan & cepat.
  • GUI (Graphical User Interface): Berbasis visual grafik, window, tombol & ikon. Sangat mudah digunakan.

Keamanan & Hak Akses

Menyediakan otentikasi (Password, Biometrik) serta mengontrol otorisasi hak akses berkas (*Read, Write, Execute*) untuk mencegah virus, malware, maupun peretasan.

Petunjuk untuk Guru Informatika & Murid

Untuk Guru Informatika:

  1. Minta murid membaca 6 Sub-Topik Materi terlebih dahulu sebagai pendalaman konsep.
  2. Arahkan murid memainkan **Game Puzzle OS** untuk menguji pemahaman visual alokasi sumber daya.
  3. Tugaskan murid membuka **Uji Kompetensi** dan mengisikan Nama, Kelas, serta Nomor Absen.
  4. Sistem secara otomatis mendeteksi jika murid keluar dari tab browser (*Anti-Cheat Log*).
  5. Setelah selesai, murid menekan tombol **"Salin Format Laporan Guru"** lalu mengirimkan salinan teks tersebut ke WhatsApp Guru atau Google Classroom.

Fitur Anti-Nyontek Aktif:

  • Tab Switching Protection: Setiap kali tab browser ditinggalkan, peringatan suara berbunyi & pelanggaran dicatat.
  • Shuffled Questions & Options: Urutan soal dan opsi A, B, C, D, E bersifat unik/acak untuk tiap peserta.
  • Disable Copy-Paste: Klik kanan dan kombinasi tombol salin-tempel diblokir.
  • Integrity Score: Skor kejujuran dihitung dari total minimnya pelanggaran selama waktu ujian.
